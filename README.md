# Prisma + NodeJS
## Steps
```
git clone https://github.com/liara-cloud/nodejs-getting-started.git
```
```
cd nodejs-getting-started
```
```
git checkout prisma
```
```
npm i
```
```
mv .env.example .env # and set your ENVs
```
```
npm run build
```
```
npm run dev
```
