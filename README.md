# Send Email Using NodeJS (nodemailer + Liara)
## Steps
```
git clone https://github.com/liara-cloud/nodejs-getting-started.git
```
```
cd nodejs-getting-started
```
```
git checkout email-server
```
```
npm i
```
```
mv .env.example # and set your ENVs
```
```
node sendEmail.js
```
